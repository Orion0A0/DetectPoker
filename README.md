Uses YOLO object detection model to analyze frames captured by the webcam. 
Uses C++ to process and filter data from the model and out the result when it has enough information to make the decision.

The YOLO model was trained by using stephanecharette/DarkNet and communicated through its DarkHelp API
##To run this program, you must have:

1. stephanecharette/DarkHelp andstephanecharette/Darknet setup on your machine
2. OpenCV and its dependencies
